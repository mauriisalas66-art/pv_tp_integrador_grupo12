## 📝 Descripción del Proyecto
Este proyecto corresponde al desarrollo de una aplicación web llamada **Panel de Control de Clientes**, creada como parte del Trabajo Práctico Integrador de la asignatura **Programación Visual**.

La aplicación ofrece funcionalidades para la autenticación de administradores, la gestion y visualizacion de información de clientes a través del consumo de una API externa, la navegación entre diferentes secciones mediante **React Router DOM**, la gestión del estado global utilizando **Context API** y el mantenimiento de la sesión del usuario mediante **LocalStorage**.
